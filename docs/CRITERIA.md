# The 33 ratio criteria

Points: Good = 2, Average = 1, Bad = 0, blank = not measurable. Score = (points + 6) / (2 × measured + 12) – the +6/+12 shrinks the score toward 50% when few ratios can be measured (e.g. banks). Banks and insurers (PSX sector codes 0806, 0807, 0812, 0813, 0815, 0819, 0836) skip the ratios marked *No*.
