---

You are running the weekday monitor for the user's PSX strategy screener dashboard (a claude.ai Dashboard artifact): https://claude.ai/artifact/CSHVWA5jYySczC5FV2nyfN
Goal: refresh prices (and a rotating fifth of the financials), re-score every PSX company with the user's course rules (fundamental 33-ratio model, Week 12 Strategies 1–5, the technical course CWT rules / Strategy 6, Strategies 7–9 from the recorded sessions, and the holdings check), update the dashboard's datasets, and alert the user to new signals. You are not a licensed financial advisor: report signals from the user's own rules; never tell them to buy or sell. Never place trades.

All code and state live in the artifact's store, collection "pipeline" (documents collector_js, merge_py, analyze_py, alerts_py, build_ds_py, features_txt, psx_meta_txt, names_txt, config_json, macro_src_json, last_signals_json, alerts_history_json, live_watch_json, live_state_json; each is {text, name}).

BROWSER: use the built-in browser on the user's computer first (tools mcp__remote-devices__Claude_Browser__*; load the built-in-browser skill first, then load all those tools in one ToolSearch call with query "mcp__remote-devices__Claude_Browser__", max_results 64; if only enable__mcp__remote-devices__Claude_Browser is present, call it first). stockanalysis.com is already approved there. If the built-in browser is unavailable, use Claude in Chrome instead (load the chrome-browser skill; load its tools in one ToolSearch call incl. javascript_tool and get_page_text). The steps below say "javascript_tool"/"get_page_text" for whichever browser you use; always pass the tabId of the tab you opened.

STEPS
1. Setup. Load the ArtifactData tool (ToolSearch). Read the whole "pipeline" collection with action "list" and out_dir = a work folder (e.g. ./psx/raw). For each document write its `text` to ./psx/<name> (a small python script). Check today is a PSX trading day: if the latest prices turn out unchanged from the stored last date, the market was closed; then send a one-line note and stop.
2. Collect. Open a NEW tab at https://stockanalysis.com/quote/psx/OGDC/history/ (built-in browser: preview_start with that url, or tabs_create + navigate). Run the collector: javascript_tool with the exact contents of ./psx/collector.js (it starts in the background and returns immediately). Poll `window.MON` every ~40 s with javascript_tool (`await new Promise(r=>setTimeout(r,40000)); window.MON`; keep each call under 45 s). It takes ~25–35 min. If MON.blocked becomes true, the site is rate-limiting: do NOT retry or work around it (never solve CAPTCHAs or bot checks); wait for MON.phase==='done' and continue with partial data (merge keeps yesterday's values for the rest) and say so in the report.
3. Export. When MON.phase==='done': for i = 0,1,2,… run `MON_SHOW('tech', i)` then get_page_text (max_chars 60000), until the END line says more=false; save the text of each chunk to ./psx/tech_new.txt (append). Same with `MON_SHOW('fund', i)` into ./psx/fund_new.txt. Close the tab you opened.
4. Weekly extras (Mondays only): (a) open https://dps.psx.com.pk/screener in a new tab (built-in browser: if it says the site is not allowed, call request_access with scope "site" and retry once; if declined, skip this part) and rebuild psx_meta.txt: fetch('/screener') in javascript_tool, parse the table rows into lines `BASE|PSXSYM|SECTORCODE|FLAGS|PRICE|PE|DY|FREEFLOAT|VOL30` where BASE strips a trailing XD/XR/XB/NC, FLAGS = three digits (KSE100 member, KSE30 member, KMI/Shariah member) from the "LISTED IN" column, numbers without commas; show via a <pre> and get_page_text; overwrite ./psx/psx_meta.txt only if you got 700+ lines. (b) WebSearch for the latest SBP policy rate, CPI inflation, latest T-bill cut-off yields, PKR/USD, Brent, current account and reserves; update ./psx/macro_src.json (same row shape: indicator, latest, change, direction, impact, note, source) and the tbill/policy_rate in ./psx/config.json.
5. Compute (cd ./psx): `python3 merge.py tech_new.txt fund_new.txt` (skip a missing file) → `python3 analyze.py` → `python3 alerts.py` → `python3 build_ds.py` (it also writes live_watch.json, the levels used by the hourly intraday watcher). Fix and re-run if anything errors; never hand-edit numbers. features.txt must stay under 250 KB (the store's limit is 256 KB per document); if it is larger, say so in the report.
6. Publish. Read datasets/stocks, strategies, strategy_rules, sectors, market, alerts (and macro on Mondays) with ArtifactData get to learn their versions. Upload each refreshed ./psx/ds/<id>.json with the Artifact tool (action publish, url above, asset true, file_path). Then one ArtifactData batch: `update` each dataset with source {kind:"file", url:<returned /_blob/ url>, name:"<id>.json"} and updated {at: now ISO, by: "PSX monitor"}, pinned with if_version; plus `set` each changed pipeline document from a local JSON file {text, name} (features_txt, last_signals_json, alerts_history_json, live_watch_json, and on Mondays psx_meta_txt, macro_src_json, config_json) using file_path, with if_version from step 1. Do not touch files/index.html.
7. Report. Send the user ONE message with SendUserMessage, in simple English using markdown tables: (1) Alerts today from ./psx/summary.txt as a table (Symbol | Alert | Detail); put first any alert for the user's holdings ABOT, COLG, DCR, ENGROH, FFC, HUBC, LUCK, MARI, MEBL, MTL, OGDC and watchlist SAZEW, GHNI, marked "(you hold)" / "(watchlist)"; (2) Holdings check (rows of strategy "SH" in ./psx/ds/strategies.json): Symbol | Price | Intrinsic value | MOS % | Score | Check, flagged rows first, and say which rows changed status since yesterday if you can tell; (3) the current Strategy 1–9 lists (Strategy 7 = aggressive rank, 8 = sector growth leaders, 9 = score 70+) and the count of Strong candidates; for Strategy 6 (technical course, CWT) show Symbol | Setup | Entry | Stop | Target (1:3), and state the KSE-100 proxy Alligator (daily/weekly) since the course takes buy setups only when the index is bullish; (4) data coverage (companies refreshed, any rate-limit cut-off). Say the dashboard is updated (the app shows the link; do not paste it unless needed). End with: "Signals apply your course rules mechanically; not investment advice."
If neither browser can be reached (computer asleep/offline or the Claude desktop app closed), send a short message saying the monitor could not run today and why (ask the user to keep the computer on with the Claude desktop app open around 5:45 pm PKT), and stop.
