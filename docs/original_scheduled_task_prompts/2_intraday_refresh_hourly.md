# PSX dashboard intraday refresh (hourly)

Schedule (cron): `CRON_TZ=Asia/Karachi 7 10-15 * * 1-5`  ·  Enabled: True

This is the instruction Claude ran on that schedule, copied for reference. It refers to Claude-only tools (ArtifactData, the built-in browser, SendUserMessage); the scripts in monitor/ and collector/ do the same steps outside Claude.

---

You are the hourly INTRADAY refresh for the user's PSX strategy screener dashboard (claude.ai Dashboard artifact https://claude.ai/artifact/CSHVWA5jYySczC5FV2nyfN). PSX trades 9:30–15:30 PKT. Goal: recompute the dashboard with today's running candle so the user sees current setups during the market. Do not send any chat message unless the run fails; the user just looks at the dashboard. You are not a licensed financial advisor; never place trades.

0. Get the current time (Asia/Karachi). If it is a Saturday/Sunday, or before 09:45 or after 16:00, stop silently.
1. Setup. Load ArtifactData (ToolSearch "select:ArtifactData"). Read the whole "pipeline" collection (action list, out_dir ./psx/raw) and write each document's `text` to ./psx/<name> (small python script). From ./psx/live_watch.json take `intraday_syms` (about 190 symbols).
2. Browser: built-in browser on the user's computer (load the built-in-browser skill, then all its tools in one ToolSearch call with query "mcp__remote-devices__Claude_Browser__", max_results 64; if only enable__mcp__remote-devices__Claude_Browser is present, call it first). If unreachable, stop silently.
3. Today's candles from PSX: open a new tab at https://dps.psx.com.pk/company/OGDC (preview_start; site already approved). Run javascript_tool that starts (in the background, without awaiting) a loop over intraday_syms in groups of 6 using jQuery.ajax({url:'/timeseries/int/'+SYM, timeout:15000}) (jQuery is required; plain fetch returns 404). Each response data is [[unixTime, price, volume], …] newest first: open = price of the LAST element, high/low = max/min price, close = data[0][1], volume = sum. Store window.__TODAYSTR = 'SYM,o,h,l,c,v;SYM,…'. Poll with short javascript_tool calls (each under 45 s) until it is set (about 1 minute), then read it (it is ~6–7k characters). Close the tab.
4. Collector in intraday mode: open a new tab at https://stockanalysis.com/quote/psx/OGDC/history/. First a javascript_tool call that sets window.MON_OPTS = {noFund:true, only:[…intraday_syms…], todayDate:'<today YYYY-MM-DD>', today:{SYM:[o,h,l,c,v], …}} from the string in step 3 (paste it exactly and verify the symbol count). Then run javascript_tool with the exact contents of ./psx/collector.js. Poll window.MON (each call under 45 s) until MON.phase==='done' (about 3 minutes). If MON.blocked becomes true, stop the run silently (never work around rate limits or bot checks).
5. Export: for i = 0,1,… run MON_SHOW('tech', i) then get_page_text (max_chars 60000) until the END line says more=false; save each chunk's lines to ./psx/tech_new.txt (append). Before trusting it, check the line count equals MON.techLines. Close the tab.
6. Compute (cd ./psx): python3 merge.py tech_new.txt → python3 analyze.py → python3 build_ds.py. Do NOT run alerts.py and do NOT save features_txt, last_signals_json or alerts_history_json (the 5:43 pm evening run keeps the official end-of-day history). Never hand-edit numbers.
7. Publish: ArtifactData get datasets/stocks, strategies, strategy_rules, sectors, market for their versions. Upload ./psx/ds/stocks.json, strategies.json, strategy_rules.json, sectors.json, market.json with the Artifact tool (action publish, url https://claude.ai/code/artifact/5c9c485f-d312-4744-92c4-e587a4c3f6a9, asset true, file_path). Then one ArtifactData batch (url https://claude.ai/artifact/CSHVWA5jYySczC5FV2nyfN) updating each dataset's source {kind:"file", url:<returned /_blob/ url>, name:"<id>.json"} and updated {at: now ISO, by: "Intraday refresh HH:MM PKT (today's candle not final)"}, pinned with if_version. Do not touch files/index.html or other pipeline documents.
If any step fails in a way you cannot fix quickly, send one short SendUserMessage saying the intraday refresh at HH:MM did not complete and why.
